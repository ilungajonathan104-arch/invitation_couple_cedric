# Jonathan & Agathe — Invitation

Projet statique prêt pour GitHub Pages.

## Mise en ligne

1. Créer un dépôt GitHub, par exemple `jonathan-agathe`.
2. Envoyer `index.html` et `.nojekyll` à la racine du dépôt.
3. Dans GitHub : **Settings → Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/ (root)`.
6. Enregistrer. GitHub Pages affichera ensuite l'adresse publique du site.

Aucune commande de build n'est nécessaire : le projet est une page HTML statique.
